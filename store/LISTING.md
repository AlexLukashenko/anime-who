## Вкладка «Store listing»

### Название (берётся из manifest.json)
```
Кто это? — персонажи аниме
```

### Краткое описание (Summary, берётся из manifest.json, ≤ 132 символа)
```
Показывает фото и имя персонажа аниме, когда о нём говорят в серии. YummyAnime (все плееры), DreamCast и другие сайты.
```

### Описание (Description)
```
Смотрите аниме и не помните, кто такой Жэньши, а кто Гаошунь? «Кто это?» подскажет прямо в плеере.

Когда в серии называют персонажа, в углу видео на несколько секунд появляется баннер: фото, имя по-русски, японское написание и роль — главный или второстепенный. Ничего не нужно ставить на паузу и гуглить.

ЧТО УМЕЕТ
• Баннер с персонажем в момент, когда его называют в реплике.
• Клик по баннеру — пауза и карточка: крупное фото, имена, сэйю, описание с Shikimori, связанные персонажи.
• Панель «Кто есть кто» (Alt+Shift+C): все персонажи сезона, сверху — кого уже упоминали в этой серии.
• Персонажи прошлых сезонов: если вспомнили героя из второго сезона, баннер покажет и его — с пометкой, откуда он.
• Режим без спойлеров: в панели только те, кого уже называли в этой или прошлых сериях.
• Кнопка «Не он» на баннере, если имя совпало с обычным словом.
• Можно выключить отдельных персонажей и выбрать, что показывать: фото, имена, роль, описание.

ГДЕ РАБОТАЕТ
• YummyAnime — все плееры (Kodik, CVH, Alloha, Aksor, VK). Аниме, серию и озвучку расширение определяет само.
• DreamCast.
• Если аниме или серия определились неправильно, их можно указать вручную ссылкой на Shikimori или MyAnimeList.
Озвучка любая.

КАК ЭТО РАБОТАЕТ
Расширение скачивает японские субтитры серии с Jimaku и ищет в репликах имена персонажей из Shikimori и AniList. Субтитры к озвучке часто сдвинуты из-за заставки студии — расширение подбирает задержку само, сравнивая речь в звуке серии с репликами. Задержку можно поправить и вручную, она запоминается для каждой озвучки.

ПРИВАТНОСТЬ
Звук обрабатывается только в браузере и никуда не отправляется. Расширение не собирает данные о вас и не показывает рекламу. В сеть уходят только запросы к Shikimori, AniList и Jimaku — за данными о персонажах и субтитрами.

ОГРАНИЧЕНИЯ
Нужны японские субтитры на Jimaku: для популярных и свежих тайтлов они обычно есть, для старых и нишевых — не всегда. Тогда можно загрузить свой файл .srt или .ass.

Исходный код открыт (MIT): https://github.com/AlexLukashenko/anime-who
Расширение не связано с Shikimori, AniList, Jimaku, YummyAnime, DreamCast и Kodik.

## Вкладка «Privacy»

### Single purpose (единственное назначение)
```
Показывает, какой персонаж аниме упоминается в текущей серии: при упоминании имени в реплике над видеоплеером появляется баннер с фото, именем и ролью персонажа, а по клику — карточка персонажа и список всех персонажей сезона.
```

### Обоснование разрешений (Permission justification)

**storage**
```
Хранит настройки расширения, задержку субтитров для каждой озвучки, ручной выбор аниме и серии, выключенных персонажей и кеш ответов Shikimori, AniList и Jimaku, чтобы не запрашивать их повторно.
```

**unlimitedStorage**
```
Кеш субтитров и данных о персонажах (включая прошлые сезоны для режима без спойлеров) может превышать стандартные 10 МБ. Расширение само ограничивает кеш 40 МБ и удаляет устаревшие записи.
```

**offscreen**
```
В offscreen-документе работает детектор речи Silero VAD (ONNX Runtime Web, WebAssembly). Он определяет моменты речи в звуке серии, чтобы автоматически подобрать задержку субтитров. Service worker не может запускать WebAssembly-модель с аудиопотоком, поэтому нужен offscreen-документ. Звук обрабатывается локально и никуда не отправляется.
```

**tabCapture**
```
Некоторые встроенные плееры не отдают звук видео напрямую. Тогда по нажатию пользователя «Слушать звук вкладки» расширение захватывает звук текущей вкладки, чтобы подобрать задержку субтитров по речи. Звук обрабатывается только локально, не записывается и не отправляется.
```

**activeTab**
```
Окно расширения обращается к активной вкладке, чтобы показать, какое аниме и серия в ней определились, менять задержку субтитров и запускать захват звука этой вкладки по действию пользователя.
```

**Host permissions** (shikimori.io, shikimori.one, graphql.anilist.co, jimaku.cc)
```
Shikimori и AniList — источники имён, фото, ролей и описаний персонажей. Jimaku — источник японских субтитров серии, в которых ищутся имена. Других запросов расширение не делает.
```

**Content scripts на <all_urls>** (если спросят про широкий доступ к сайтам)
```
Видео на поддерживаемых сайтах (YummyAnime, DreamCast) воспроизводится во встроенных плеерах (Kodik, CVH, Alloha, Aksor, VK и др.), которые загружаются в iframe с разных и часто меняющихся доменов. Скрипт должен работать внутри этих iframe, чтобы найти видео и показать баннер поверх него. Скрипт сразу завершает работу, если ни сам фрейм, ни страница верхнего уровня не относятся к YummyAnime, DreamCast или Shikimori, и ничего не читает на других сайтах.
```

### Remote code
**No, I am not using remote code.** (ONNX Runtime и модель лежат в пакете, `vendor/`.)

### Data usage — какие галочки ставить
Ставим:
- ☑ **Authentication information** — необязательный API-ключ Jimaku, который пользователь вводит сам; хранится локально и отправляется только на jimaku.cc.
- ☑ **Website content** — название аниме со страницы (для поиска на Shikimori, когда на странице нет ссылки на Shikimori/MAL).

Не ставим: Personally identifiable info, Health, Financial, Personal communications, Location, Web history, User activity.

Три подтверждения внизу — отметить все:
- ☑ I do not sell or transfer user data to third parties, outside of the approved use cases
- ☑ I do not use or transfer user data for purposes that are unrelated to my item's single purpose
- ☑ I do not use or transfer user data to determine creditworthiness or for lending purposes

## Что может затормозить проверку
- `<all_urls>` в content scripts — из-за этого проверка дольше обычной («in-depth review»). Обоснование выше.
- На скриншотах кадры аниме и арты персонажей — чужой контент. Обычно для таких расширений это проходит, но если отклонят за IP, замените кадры на нейтральный фон.
- На `screenshot-3-card.png` в описании персонажа есть фраза про «сексуальные фантазии» (это текст с Shikimori). Если не хотите рисковать отметкой «mature», перескриньте карточку другого персонажа.
