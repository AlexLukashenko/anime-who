Кто это? — настройки

Что и кого показывать, задержка субтитров и автоподбор по звуку — во вкладке «Настройки» в окне расширения (иконка на панели Chrome).

Jimaku (субтитры)

Без ключа расширение читает публичные страницы jimaku.cc. С ключом (бесплатно: аккаунт на jimaku.cc → Account → API key) запросы легче и надёжнее.

Данные

Горячие клавиши: Alt+Shift+C — панель персонажей, Alt+Shift+S — подобрать задержку заново по звуку. Изменить: chrome://extensions/shortcuts
